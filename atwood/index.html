實驗：用阿特午機測重力加速度 g
固定 h，改變兩邊質量，測落下時間 t，算出 a = 2h／t²。以 (m₂ − m₁)／(m₁ + m₂) 為橫軸、a 為縱軸，直線的斜率就是 g。兩邊質量越接近，加速度越小、越容易計時。

公式與教學提示
核心公式（符號與單位）
  • 阿特午機（m₂ > m₁）：對兩物體分別列牛頓第二定律 m₂g − T = m₂a、T − m₁g = m₁a，解得 a = (m₂ − m₁)g／(m₁ + m₂)（m/s²）、T = 2m₁m₂g／(m₁ + m₂)（N）。
  • 桌面連體：T − μm₁g = m₁a、m₂g − T = m₂a，解得 a = (m₂ − μm₁)g／(m₁ + m₂)、T = m₂(g − a)。若 m₂ ≤ μm₁，系統靜止，T = m₂g。
  • 由靜止移動 h：h = ½at²，所以 a = 2h／t²；末速 v = at = √(2ah)。
  • 系統觀點：把兩物體當成一個系統，「推動的力」(m₂ − m₁)g 除以「總質量」(m₁ + m₂)。
  • 符號：m₁、m₂ 質量（kg）；T 繩張力（N）；μ 動摩擦係數；g 重力加速度（m/s²）。

理想化假設：繩子不可伸長、質量不計；滑輪質量與軸承摩擦不計（所以兩邊張力相等）；不計空氣阻力。桌面連體模式中，最大靜摩擦係數與動摩擦係數取同一個 μ。

建議講解順序
  1. 先讓兩邊一樣重，釋放：不動。再讓 m₂ 稍重，請學生預測 a 是否等於 g。
  2. 看數據：張力 T 介於 m₁g 與 m₂g 之間，兩個物體各自的合力都不為零。
  3. 把 m₂ 調到很大：a 趨近 g，但永遠小於 g。
  4. 切到桌面連體：光滑桌面時 a = m₂g／(m₁ + m₂)，強調 T 不等於 m₂g。
  5. 加入摩擦：找出剛好拉不動的 m₂。
  6. 回到阿特午機做實驗：記錄 4 組以上，由斜率求 g；再挑戰未知星球。
可以問學生的問題
  • m₁ = m₂ 時，張力是多少？物體一定靜止嗎？（T = mg；可以等速運動）
  • 兩邊各加上相同的質量，加速度變大還是變小？（變小，推動的力不變、總質量變大）
  • 釋放後，滑輪上方掛鉤受的力是 (m₁ + m₂)g 嗎？（不是，是 2T，比較小）
  • 桌面連體中，把 m₁ 與 m₂ 對調，加速度一樣嗎？（光滑時不同：推動的力變成 m₁g）
  • 為什麼當年阿特午要用這個裝置測 g，而不直接讓物體自由落下？（加速度小，時間長，容易量）
常見迷思
  • 「繩子張力等於懸掛物的重量」：只有靜止或等速時才成立；加速下降的物體，T < mg。
  • 「重的那邊加速度比較大」：繩子不可伸長，兩物體加速度大小相同。
  • 「張力等於兩物重量的平均」：T = 2m₁m₂g／(m₁ + m₂) 是調和平均的形式，不是算術平均。
  • 「加速度等於 g」：只有自由落體才是 g；這裡被另一個物體「拖住」，a < g。

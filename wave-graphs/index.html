公式與教學提示
核心公式（符號與單位）
  • 行進波：y(x, t) = A sin[2π(x/λ ∓ t/T)]（「−」：向右（+x）行進；「＋」：向左行進）。A：振幅，λ：波長（m），T：週期（s）。
  • 波速：v = λ / T = f λ（f = 1/T，單位 Hz）。波速只由介質決定；改變 f，波長跟著變。
  • y–x 圖：固定 t，看所有位置的位移；橫軸是位置，可以讀出 λ、A。y–t 圖：固定 x，看一個質點的位移隨時間；橫軸是時間，可以讀出 T、A。
  • 質點的垂直速度：vy = ∂y/∂t = −(±v)·∂y/∂x。向右行進的波，y–x 圖「斜率為負」的位置，質點向上運動。
  • 兩點相距 Δx：相位差 = 2πΔx/λ。位移總是相反 → Δx = (n + ½)λ；總是相同 → Δx = nλ。

理想化假設：單一頻率的正弦行進波，無衰減；介質質點只作上下（橫向）運動；範例 13、14 的圖形以講義數值重建（範例 13：T = 0.4 s；範例 14：λ = 4 m）。

建議講解順序
  1. 模式①：先暫停，只看 y–x 圖「像照片」，指出 λ；再看 P 點，y–t 圖「像影片」，指出 T。
  2. 勾「顯示下一瞬間的波形」：波形向右平移一點點，P 點就跟著往上（或下）→ 質點只上下動，波形向前傳。
  3. 按「凍結快照」，再播放一小段：兩條 y–x 曲線的水平間隔就是 vΔt。
  4. 模式②：學生自己判斷方向與波速，再看解答與驗證動畫。
  5. 模式③、④：範例 14 的多解性（n 整波）、範例 13 的相位差條件。
可以問學生的問題
  • y–x 圖的橫軸 1 個週期是什麼？（一個波長）y–t 圖呢？（一個週期）
  • 向右行進的波，波峰「右邊」的質點接下來是向上還是向下？（向上，因為波峰要移過來）
  • 範例 14：為什麼 t = 0 與 t = 1 秒的波形，無法直接得知波速？（可能多走了整數個波長）
  • 範例 13：相距 1.5 cm 的兩點位移和恆為零，波長有哪些可能？
常見迷思
  • 「y–t 圖的橫軸是位置」：y–t 圖是同一個質點的位移對時間，橫軸是時間。
  • 「波往右傳，質點也往右跑」：質點只上下振動，沒有隨波前進。
  • 「看 y–x 圖的斜率正負就能知道波的方向」：必須和質點此刻上下運動（由 y–t 圖得知）一起判斷。
  • 「λ = vT」只能用 y–t 圖」：λ 要從 y–x 圖讀，T 要從 y–t 圖讀，兩張圖要互相搭配。

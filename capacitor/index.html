公式與教學提示
核心公式（符號與單位）
  • 電容的定義 C = Q／V（法拉 F = C/V）：每 1 V 電壓能儲存多少電量。
  • 平行板電容 C = κε₀A／d；ε₀ = 8.85 × 10⁻¹² F/m（真空電容率）、A 極板面積（m²）、d 板距（m）、κ 介電常數（真空為 1）。
  • 板間是均勻電場 E = V／d = σ／(κε₀)（V/m），σ = Q／A 是面電荷密度。
  • 儲存的電能 U = ½CV² = ½QV = Q²／2C（J）。
  • 接著電池：V 不變，Q = CV 隨 C 改變。拆掉電池：Q 不變（電荷無路可走），V = Q／C 隨 C 改變。

理想化假設：極板很大、板距很小，不計邊緣的電場彎曲；介質填滿整個板間；電池是理想電壓源、導線沒有電阻（充放電瞬間完成）；拆掉電池後沒有漏電。

建議講解順序
  1. 先看定義：電池 6 V，讀出 C 與 Q，驗證 Q = CV。
  2. 接著電池，把板距拉大：C 變小、V 不變，所以 Q 變小（電荷流回電池）、E 變小。
  3. 按「設為比較基準」後切到「拆掉電池」，再把板距拉大：Q 不變、V 變大，E 不變！
  4. 比較兩種情況下電能的變化：拆掉電池後拉開極板，電能增加——能量從哪裡來？
  5. 插入介質（κ 變大）：兩種情況各有什麼變化？
  6. 做實驗：C–1／d 圖求 ε₀，再挑戰未知介質。
可以問學生的問題
  • 板距加倍，電容變成幾倍？面積加倍呢？（一半；兩倍）
  • 拆掉電池後把板距加倍，電壓、電場、電能各變成幾倍？（2、1、2）
  • 接著電池把板距加倍，電量、電場、電能各變成幾倍？（½、½、½）
  • 拆掉電池後拉開極板，增加的電能從哪裡來？（外力克服兩板間的吸引力所作的功）
  • 為什麼插入介質可以增加電容？（介質極化後抵消部分電場，同樣的電量只產生較小的電壓）
常見迷思
  • 「電容大就是存的電多」：電量 Q = CV，還要看電壓；電容是「每伏特能存多少」。
  • 「改變板距時電壓一定不變」：只有接著電池才是；拆掉電池後是電量不變。
  • 「拆掉電池後拉開極板，電場會變小」：電量不變、面電荷密度不變，所以電場不變，電壓反而變大。
  • 「電容器兩板的總電量是 2Q」：兩板帶等量異號電荷 +Q 與 −Q，「電量 Q」指的是其中一板的電量。

公式與教學提示
核心公式（符號與單位）
  • 水平：等速度運動 vx = v₀cosθ，x = v₀cosθ · t。
  • 鉛直：等加速度（加速度 −g）vy = v₀sinθ − gt，y = h₀ + v₀sinθ · t − ½gt²。
  • h₀ = 0 時：飛行時間 T = 2v₀sinθ／g；最大高度 H = v₀²sin²θ／(2g)；射程 R = v₀²sin2θ／g，θ = 45° 最遠。
  • 水平與鉛直運動互相獨立：水平射出的球與同高度自由落下的球，鉛直位置完全相同，同時著地。
  • 軌跡是拋物線：y = h₀ + x tanθ − g x²／(2v₀²cos²θ)。

理想化假設：質點、g 為定值、不考慮地球自轉；預設真空。打開阻力後，改以 a = −g ŷ − k·v 數值積分（RK4），此時射程縮短、軌跡不再對稱，公式不再成立。

建議講解順序
  1. 先選「水平拋射 vs 自由落體」，打開頻閃：兩球在同一水平線上，說明鉛直方向互相獨立。
  2. 回到拋射運動：看 vx–t 是水平線、vy–t 是斜率 −g 的直線。
  3. 頂點：vy = 0 但 vx ≠ 0，速度不是零、加速度仍是 g。
  4. 固定 v₀ 改 θ：30° 與 60° 射程相同、45° 最遠；加上 h₀ 後最佳角度小於 45°。
  5. 打開阻力：與真空理論軌跡比較，看射程與對稱性的變化。
  6. 月球／木星：改 g，預測飛行時間與射程比例再驗證。
可以問學生的問題
  • 最高點時速度是零嗎？加速度呢？
  • 為什麼 30° 與 60° 射程相同？（sin2θ 相同）
  • 從高台水平射出與直接落下，哪個先著地？為什麼？
  • 把同樣的球拿到月球，射程變幾倍？（g 的倒數比：約 6 倍）
常見迷思
  • 「水平速度越大，掉得越慢」：鉛直下落與水平速度無關。
  • 「最高點加速度為零」：加速度全程是 g，向下。
  • 「45° 永遠最遠」：只在起點與落點同高、無阻力時成立。

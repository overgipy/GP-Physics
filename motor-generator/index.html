判斷方向的定則安培右手開掌定則（F = qv × B）冷次定律＋右手螺旋定則
線圈中的另一個效應線圈轉動，也產生感應電動勢：反電動勢 ε = NBAω sinφ，阻礙電流；轉速越高，電流越小線圈有電流，也受磁力：反向力矩 τ = NBAI sinφ，阻礙轉動；負載電流越大，越費力
換向器每半圈換向，使力矩方向不變，線圈能持續同向轉動使輸出電流方向不變（脈動直流）
滑環力矩正負交替，淨力矩為 0，只會擺動（不能持續轉）輸出交流電：ε = εmax sin ωt
中性面（φ = 0、π：線圈平面 ⊥ B）線圈力矩為 0；換向器在此處換向磁通量最大，但 dΦ/dt = 0 → ε = 0
主要公式τ = NBAI sinφ；I = (V − 反電動勢) ÷ Rε = NBAω sinφ；εmax = NBAω；I = ε ÷ (R + RL)

兩者互為逆過程：把馬達的電源拆掉、改接燈泡、讓它靠慣性繼續轉，就變成發電機（按「🔌 斷電，改接燈泡」試試）；反過來把發電機接上電池，它就會轉成馬達。

公式與教學提示
核心公式（符號與單位）
  • 線圈：N 匝、面積 A = 0.020 m²（寬 0.10 m、長 0.20 m）、電阻 R = 2.0 Ω；磁場 B（T）均勻，向右。φ 為線圈法線 n 與磁場 B 的夾角。
  • 磁通量：Φ = N B A cosφ（φ = 0 時線圈平面垂直磁場，磁通量最大）。
  • 發電機：線圈以角速度 ω 轉動，φ = ωt，ε = −dΦ/dt = N B A ω sinφ，最大值 εmax = NBAω；頻率 f = ω/2π。
  • 馬達：每邊導線受力 F = I L B（開掌定則），對轉軸的力矩 τ = N B A I sinφ；線圈轉動時也產生反電動勢 ε = NBAω sinφ。
  • 馬達電路：V = IR ＋ 反電動勢（以換向器取絕對值）；能量：VI = I²R ＋ τω（電功率 = 熱損失 ＋ 機械功率）。
  • 發電機的能量：外力的機械功率 = εI = I²(R + RL)（線圈熱損 ＋ 燈泡功率）。

理想化假設：線圈為矩形、邊長均勻、磁場均勻且只在畫面所示範圍；忽略線圈自感與渦電流；電池為理想電池；摩擦力矩為 b ω（b = 0.02 N·m·s/rad）；轉動慣量 J = 0.10 kg·m²。換向器於 φ = 0、π 瞬間（中性面）換向。本頁數值由運動方程式 J dω/dt = τ_磁 − τ_L − bω 以逐步積分求得。

建議講解順序
  1. 先用馬達模式＋換向器：從端視圖看兩條導線受力，用開掌定則判斷方向；問學生，為什麼過了中性面要換電流方向？
  2. 換成滑環：線圈只會擺動，說明換向器的作用。
  3. 加上負載力矩：轉速下降、電流上升。引入反電動勢：馬達也在發電。
  4. 按「🔌 斷電，改接燈泡」：同一個裝置變成發電機，燈泡亮一下就暗。
  5. 切到發電機模式：固定轉速，看 Φ–t 與 ε–t 圖相差 90°；中性面 ε = 0，與磁力線平行時 ε 最大。
  6. 調 ω、B、N，驗證 εmax = NBAω；切換換向器與滑環，比較交流與脈動直流。
可以問學生的問題
  • 為什麼馬達剛啟動時電流最大、轉速上升後電流變小？（反電動勢）
  • 馬達卡住不動（堵轉）會怎樣？（沒有反電動勢，電流很大，容易燒毀）
  • 發電機輸出的電流越大，轉動時要用的力越大嗎？為什麼？（冷次定律、磁力阻礙轉動）
  • Φ 最大的時候，ε 是多少？ε 最大的時候，Φ 是多少？
  • 轉速加倍，εmax 和頻率各變為幾倍？
  • 手搖發電機燈泡越亮，手為什麼越吃力？（能量守恆）
常見迷思
  • 「馬達只有磁力、沒有感應電動勢」：只要線圈在轉，磁通量就在變，必有反電動勢（冷次定律的結果）。
  • 「發電機不需要輸入能量」：輸出的電能來自轉動的力學能；輸出電流越大，需要的外力矩越大。
  • 「磁通量最大時感應電動勢最大」：相反，Φ 最大（φ = 0）時 ε = 0；線圈平面平行磁場時 Φ = 0 而 ε 最大。
  • 「換向器使電流變成直流」（馬達）：電池本來就是直流；換向器是讓線圈中的電流每半圈反向，力矩才不會反向。

公式與教學提示
核心公式（符號與單位）
  • 互感：二次線圈的磁通量鏈 Λ₂ = M I₁（M：互感，單位 H；與兩線圈的圈數、大小、距離有關，距離越近 M 越大）。
  • 法拉第定律：ε₂ = −dΛ₂/dt = −M·dI₁/dt（線圈位置不動時）；感應電流 I₂ = ε₂ ÷ R₂。I₂ 看的是 I₁ 的「變化率」（I₁–t 圖的斜率），不是 I₁ 的大小。
  • 若線圈也移動，ε₂ = −(M·dI₁/dt + I₁·dM/dt)：M 隨距離改變，也會使磁通量改變。
  • 方向（冷次三步）：① 磁通量增加或減少 → ② 感應磁場與原磁場「反向（增加時）」或「同向（減少時）」→ ③ 右手螺旋定則判斷 I₂。
  • 範例 10 的答案：I₂ 為 0 發生在 dI₁/dt = 0，即 I₁–t 圖斜率為 0（極大值與極小值）的時刻。
  • 並排（共平面）的兩個線圈：左線圈的磁場在右線圈處，方向與「線圈內部」相反（磁力線在外部折回），所以逆時針的左線圈使右線圈有向下的磁通量。

理想化假設：兩線圈各 N₁ = 200 匝、N₂ = 100 匝、半徑 5.0 cm，二次線圈電阻 R₂ = 0.50 Ω；互感 M 以紐曼公式（M = μ₀/4π ∮∮ dl₁·dl₂/r）數值積分計算，不是示意數字。忽略二次線圈的自感（I₂ 的磁場對一次線圈的影響）；模式①中的 I₁ 以時間常數 τ 趨近穩定值，忽略斷開瞬間的火花；模式③中左線圈的電流由外部電源提供，不受右線圈影響。

建議講解順序
  1. 模式①：閉合開關，I₁ 由 0 逐漸增加，只有「增加的這段時間」有 I₂；穩定後 I₂ = 0。
  2. 用三步判斷法：磁通量增加 → B′ 反向 → I₂ 與 I₁ 反向。再按「打開開關」：磁通量減少 → I₂ 與 I₁ 同向。
  3. 調 R₁（滑動變阻器）：電阻變小，I₁ 增加，與閉合開關效果相同。
  4. 模式②：先看 I₁–t 圖，問學生：I₂ 何時為 0？何時最大？再請學生手繪 I₂–t，最後顯示解答。
  5. 強調：I₂–t 圖就是 −(I₁–t 圖的斜率)，與 I₁ 的大小無關。
  6. 模式③：逐項驗證範例 7 的選項，注意並排線圈的磁場方向在外部是反向的。
可以問學生的問題
  • I₁ 很大但穩定不變，I₂ 是多少？為什麼？
  • I₁–t 圖在極大值附近，I₂ 是多少？I₁ 通過 0 的時候呢？
  • 斜率最大的位置，I₂ 的絕對值是不是最大？它的正負由什麼決定？
  • 兩線圈靠得更近，I₂ 的大小與方向怎麼變？（大小變大，方向不變）
  • 範例 7 為什麼左線圈「往右移」不一定使右線圈得到順時針？（要看左線圈的電流方向）
常見迷思
  • 「I₁ 越大，I₂ 越大」：看的是 I₁ 的變化率；I₁ 穩定時 I₂ = 0。
  • 「感應電流與原電流永遠反向」：只有原電流（磁通量）增加時反向；減少時同向。
  • 「開關閉合後，I₂ 一直存在」：電流穩定後，磁通量不再變化，I₂ 回到 0。
  • 「並排線圈和上下線圈的磁場方向一樣」：並排時右線圈在左線圈的「外面」，磁力線方向與內部相反。

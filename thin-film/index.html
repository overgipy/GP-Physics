🫧 薄膜干涉

公式與教學提示
核心公式（符號與單位）
  • 兩道反射光：光線 1 由薄膜上表面反射；光線 2 穿過薄膜，由下表面反射後回到上表面射出。兩者再疊加。
  • 額外光程（光線 2 多走的路）：2 nf d cosθ′（nf：薄膜折射率；d：厚度，nm；θ′：薄膜內折射角，n₁ sinθ = nf sinθ′）。垂直入射時 = 2 nf d。
  • 反射時的相位改變：光由折射率小 → 大的介質反射，反射波相位改變 π（半波長）；由大 → 小則沒有改變。
  • 總相位差：δ = (4π nf d cosθ′ / λ) + (π，若兩次反射中恰有一次相位改變 π)，λ 為空氣中波長。
  • δ = 2πm → 建設性干涉（亮）；δ = (2m+1)π → 破壞性干涉（暗）。
  • 兩次反射的「相位改變次數」為奇數（肥皂膜、浮在水上的油膜）：2 nf d cosθ′ = mλ → 暗；(m+½)λ → 亮。
    為偶數（鏡頭鍍膜、玻璃上的膜）：2 nf d cosθ′ = mλ → 亮；(m+½)λ → 暗。
  • 鏡頭增透膜：最薄的暗條件 d = λ／(4 nf)，且 nf = √(n₁n₂) 時兩道反射光振幅相等，可完全抵消。

理想化假設：薄膜均勻、兩界面平行且平滑；以 s 偏振的菲涅耳反射率計算振幅，並計入多次反射（艾里公式）；圖中「兩道反射光」是前兩次反射的近似，用來說明相位關係；反射色以 6500 K 白光、CIE 1931 色彩匹配函數近似計算，亮度為方便觀看已放大，顏色僅供示意（實際顏色依螢幕而異）。

建議講解順序
  1. 模式①：先選「肥皂膜」，d = 0：兩道反射光幾乎重合，但其中一道有 π 相位改變 → 反相 → 暗。這就是肥皂膜最上端為什麼是黑的。
  2. 慢慢增加 d：光程差增加，直到 2nfd = λ/2（波形同相）→ 亮；再到 2nfd = λ → 暗。
  3. 改成「鏡頭鍍膜」：兩次反射都有 π 相位改變，條件整個反過來：d = λ/(4nf) 時反射最少（增透）。
  4. 模式②：白光含各色，每個 d 會讓不同波長亮或暗，看到的是互補後的顏色。
  5. 模式③：厚度連續變化，同一種色光出現週期性亮暗條紋；白光出現彩色條紋，越厚越淡（各色條紋重疊）。
  6. 改變入射角：光程差變小 → 顏色偏向短波長（藍移）。
可以問學生的問題
  • d = 0 的肥皂膜為什麼看起來是黑的？（兩道反射光反相）
  • 肥皂膜越薄顏色越…？越厚為什麼顏色變淡？（厚度很大時，各波長的亮暗位置錯開，疊加成白光）
  • 鍍膜眼鏡看起來帶紫紅色，為什麼？（綠光附近被抵消，剩下紅與藍反射）
  • 從斜的角度看肥皂泡，顏色會變嗎？（會，θ′ 改變，光程差改變）
  • 為什麼薄膜干涉需要「薄」？（光的相干長度很短，太厚時兩道反射光不相干）
常見迷思
  • 「只要兩道光有光程差 λ/2 就是暗」：還要看反射時有沒有 π 的相位改變，兩者要一起算。
  • 「光線在薄膜中波長不變」：薄膜中波長 λ/nf 變短，所以光程差是 nf × 幾何路程。
  • 「顏色是薄膜本身的顏色」：肥皂水是無色的，顏色來自干涉（結構色）。
  • 「透射光也會亮暗互補」：能量守恆，反射變暗的波長，透射就變亮。

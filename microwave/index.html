公式與教學提示
核心公式（符號與單位）
  • 電磁波在真空（空氣）中的速率 c = fλ = 3.00 × 10⁸ m/s；10.5 GHz 的微波 λ ≈ 2.86 cm。
  • 反射定律：反射角 = 入射角（都由法線量起），入射線、反射線與法線在同一平面。
  • 駐波：入射波與反射波疊加，金屬板表面電場為零（節點）；相鄰節點（或腹點）相距 λ／2，節點位置 x = n·λ／2。
  • 偏振（馬呂士定律）：接收天線只接收沿天線方向的電場分量，I = I₀cos²φ；φ = 90° 時收不到。
  • 金屬柵欄：電場平行金屬條時，電子被驅動而把波反射回去；只有垂直金屬條的電場分量能通過。
  • 電磁波是橫波：電場、磁場都垂直於傳播方向，所以才有偏振現象（縱波沒有）。

理想化假設：發射器送出單一頻率、沿固定方向偏振的平面波；金屬板是理想導體（完全反射）；不計桌面、牆壁的雜散反射與波束擴散造成的強度衰減。反射模式的讀數隨角度的變化用固定寬度的波束形狀近似；讀數是相對強度（最大 100）。

建議講解順序
  1. 反射：固定入射角，慢慢轉接收器，在哪個角度讀數最大？換幾個入射角驗證。
  2. 駐波：沿著發射器與金屬板的連線移動探測器，讀數忽大忽小；找出幾個讀數最小的位置。
  3. 記錄 4 個以上節點，由間距求波長，再算頻率，與標示值比較。
  4. 偏振：把接收器繞軸轉 90°，讀數歸零；轉 45° 是多少？
  5. 放入金屬柵欄：金屬條「平行」電場時反而擋住——和直覺（柵欄讓平行的東西穿過）相反。
  6. 最後挑戰未知頻率。
可以問學生的問題
  • 相鄰兩個節點相距 1.43 cm，波長與頻率是多少？（2.86 cm；約 10.5 GHz）
  • 接收器轉 60°，讀數剩下多少？（cos²60° = 25%）
  • 為什麼聲波沒有偏振現象？（聲波是縱波，振動方向只有沿傳播方向一種）
  • 金屬柵欄的金屬條與電場夾 45° 時，接收器（不轉）讀數是多少？（sin⁴45° = 25%）
  • 微波爐門上的金屬網孔，為什麼擋得住微波卻看得到裡面？（孔徑遠小於微波波長、遠大於可見光波長）
常見迷思
  • 「柵欄的縫與電場平行時，波才穿得過去」：相反，電場平行金屬條時會在金屬條上驅動電流而被反射。
  • 「駐波的節點相距一個波長」：相鄰節點相距半個波長。
  • 「接收器轉 45°，讀數就剩 0.71 倍」：電場分量剩 cos45° ≈ 0.71 倍，但讀數是強度（正比於電場的平方），所以剩一半。
  • 「電磁波需要介質才能傳播」：電磁波是電場與磁場的振盪，真空中就能傳播。

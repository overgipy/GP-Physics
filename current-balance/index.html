電流天平：磁力與砝碼重量平衡

實驗：由 F–(Is·I) 圖求真空磁導率 μ₀
每改變一次電流，就調整砝碼到平衡，此時磁力 F = mg。按「平衡後記錄」會自動找出平衡所需的砝碼質量。以 Is·I 為橫軸、F 為縱軸是通過原點的直線，斜率 = μ₀nL。

公式與教學提示
核心公式（符號與單位）
  • 長螺線管內部的磁場 B = μ₀ n Is（T）；μ₀ = 4π × 10⁻⁷ T·m/A，n 每公尺匝數（匝/m），Is 螺線管電流（A）。方向沿管軸，由安培右手定則決定。
  • 載流導線在磁場中受力 F = I L B sinθ（N）；導線與磁場垂直時 F = ILB。方向用右手開掌定則（或 F = IL × B）。
  • U 形導線兩側與磁場平行的部分不受力，只有末端長 L、與磁場垂直的那一段受力。
  • 平衡條件（兩臂等長）：mg = I L B = μ₀ n Is I L。
  • 所以 F ∝ I（固定 B）、F ∝ Is（固定 I）、F ∝ L；F–(Is·I) 圖的斜率 = μ₀nL。

理想化假設：螺線管夠長，內部磁場均勻且不計地磁；天平導線末端完全在均勻磁場內並與磁場垂直；天平兩臂等長、支點無摩擦；g = 9.8 m/s²。天平傾斜的動畫只是示意。

建議講解順序
  1. 先只開螺線管電流：有磁場，但天平導線沒電流，不受力。
  2. 再開天平電流：末端被往下推，天平傾斜；調砝碼到平衡，讀出磁力。
  3. 把 I 加倍：砝碼也要加倍；再把 Is 加倍，同樣加倍——F 與兩個電流都成正比。
  4. 把天平電流反向：力變成向上，砝碼放這一端就無法平衡。
  5. 改變 L 與匝數 n，看磁力怎麼變。
  6. 做實驗：F–(Is·I) 圖求 μ₀，再挑戰未知匝數。
可以問學生的問題
  • U 形導線的兩側也有電流，為什麼不受磁力？（電流方向與磁場平行，sinθ = 0）
  • 兩個電流同時反向，磁力方向會變嗎？（不變：B 反向、I 也反向）
  • n = 2000 匝/m、Is = 3 A 時，管內磁場多大？（約 7.5 mT，約地磁的 150 倍以上）
  • 如果 I 與 Is 用同一個電源串聯（I = Is），F 與電流是什麼關係？（F ∝ I²）
  • 為什麼要用螺線管而不是磁鐵？（磁場大小可由電流計算，才能求出 μ₀）
常見迷思
  • 「導線有電流就會受磁力」：電流與磁場平行時不受力。
  • 「磁力的方向沿著磁場方向」：磁力同時垂直於電流與磁場。
  • 「螺線管的磁場和長度、半徑有關」：理想長螺線管內部 B = μ₀nI，只與匝數密度和電流有關。
  • 「砝碼質量就是磁力」：平衡時磁力等於砝碼的重量 mg，單位要換成牛頓。

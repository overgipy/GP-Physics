公式與教學提示
核心公式（符號與單位）
  • 力矩 τ = r F sinθ = 力 × 力臂（N·m）；力臂是轉軸到力的作用線的垂直距離。
  • 靜力平衡的兩個條件：合力為零（ΣF = 0）且對任一點的合力矩為零（Στ = 0）。
  • 蹺蹺板：以支點為轉軸，mAg·dA = mBg·dB（加上木板自重的力矩）；支點的支撐力 = 所有重量的總和。
  • 重心：xcm = Σmᵢxᵢ／Σmᵢ；整個系統的重心在支點正上方時平衡。
  • 梯子（牆光滑、地面粗糙）：鉛直方向 N地 = (m人 + m梯)g；水平方向 f = N牆；以梯腳為轉軸 N牆 L sinθ = (m梯g·L／2 + m人g·d) cosθ。
  • 不滑倒的條件：f ≤ μsN地，即需要的 μ = (m梯／2 + m人d／L)／[(m人 + m梯) tanθ] ≤ μs。

理想化假設：木板與梯子是均勻的剛體（重心在中點）；重物與人視為質點；支點無摩擦；牆面完全光滑（只給垂直牆面的正向力）；g = 9.8 m/s²。蹺蹺板傾斜的動畫只是示意，不是真實的轉動過程。

建議講解順序
  1. 蹺蹺板：先讓兩邊一樣重、距離一樣；再把一邊變重，問要怎麼移動才能再平衡。
  2. 看數據：平衡時兩邊「質量 × 距離」相等，重的要靠近支點。
  3. 加上木板質量、把支點移離中央：木板自己的重量也有力矩，作用在重心。
  4. 做未知質量挑戰（就是桿秤的原理）。
  5. 切到梯子：先畫出四個力，再選梯腳當轉軸，為什麼選這裡最方便？
  6. 讓人往上爬：需要的摩擦力越來越大，超過最大靜摩擦就滑倒；再調整角度與 μ 比較。
可以問學生的問題
  • 40 kg 的人坐在離支點 1.5 m 處，60 kg 的人要坐在哪裡才平衡？（1.0 m）
  • 平衡時支點的支撐力是多少？與重物的位置有關嗎？（總重量；無關）
  • 為什麼人爬得越高，梯子越容易滑？（人的重力對梯腳的力矩變大，牆的正向力與所需摩擦力都變大）
  • 梯子擺得越陡越安全還是越危險？（越陡，所需摩擦越小，越不容易滑）
  • 如果地面光滑、牆面粗糙，梯子能平衡嗎？（不能，水平方向沒有力可以抵消牆的正向力）
常見迷思
  • 「兩邊一樣重才會平衡」：要比的是力矩（力 × 力臂），不是重量。
  • 「合力為零就會平衡」：合力為零但合力矩不為零時，物體會轉動（力偶）。
  • 「力矩一定要對支點算」：平衡時對任何一點的合力矩都是零，選未知力通過的點可以少算幾個力。
  • 「摩擦力一定等於 μN」：靜摩擦力是「需要多少給多少」，μsN 只是上限。

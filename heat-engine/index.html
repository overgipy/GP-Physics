公式與教學提示
核心公式（符號與單位）
  • 熱力學第一定律：ΔU = Q + W（Q：氣體吸收的熱，W：外界對氣體作的功；若把 W 改成「氣體對外作功」，則寫成 ΔU = Q − W）。
  • 理想氣體：PV = nRT；內能只和溫度有關：ΔU = n CV ΔT（單原子 CV = 3R/2，雙原子 5R/2）。
  • P–V 圖上，曲線下方的面積 = 氣體對外所作的功；循環一圈，圍起來的面積 = 淨功，順時針是熱機（淨功為正）。
  • 等壓：W氣體對外 = PΔV；等容：W = 0，Q = ΔU；等溫：ΔU = 0，W氣體對外 = nRT ln(V2/V1)；絕熱：Q = 0，ΔU = W。絕熱過程：PVγ = 定值（γ = CP/CV）。
  • 熱機效率：η = W淨 ÷ Q吸 = 1 − Q放 ÷ Q吸；卡諾效率（上限）ηC = 1 − TC/TH。奧圖循環：η = 1 − r1−γ。

理想化假設：1 mol 的理想氣體，每個過程都是可逆的準靜態過程；奧圖與史特林循環的熱量來源視為外部熱庫，史特林循環沒有再生器（所以效率低於卡諾）。P 單位 kPa、V 單位 L，PV 的乘積正好是焦耳（J）。

建議講解順序
  1. 先從矩形循環開始：功就是長方形的面積；每一邊的 Q、W、ΔU 都能手算。
  2. 驗證：走完一圈，ΔU 總和為 0，所以 Q淨 = W淨（吸熱 − 放熱 = 對外淨功）。
  3. 切換功的符號慣例，讓學生看出：只是 W 的定義不同，物理結果完全一樣。
  4. 換卡諾循環：等溫（ΔU = 0，吸的熱全變成功）、絕熱（Q = 0，用內能換功）。
  5. 比較四種循環的效率；調整溫度或壓縮比，看效率怎麼變。
  6. 問：為什麼史特林循環的效率低於同溫度範圍的卡諾？（等容加熱也要吸熱）
可以問學生的問題
  • 在 P–V 圖上，順時針與逆時針的循環，淨功的正負有什麼不同？（逆時針：外界作功，冷氣機／冰箱）
  • 等溫膨脹時氣體吸熱，但內能沒有增加，熱量跑去哪裡？（全部變成對外作的功）
  • 絕熱壓縮時溫度為什麼上升？（外界作功，Q = 0，所以 ΔU = W > 0）
  • 把 TC 降到接近 0 K，效率會是 100% 嗎？（卡諾效率上限趨近 100%，但 T = 0 K 做不到）
常見迷思
  • 「吸熱就一定升溫」：等溫膨脹吸熱，溫度不變。
  • 「循環一圈，Q 的總和等於零」：循環一圈 ΔU = 0，所以 Q淨 = −W（外界對氣體作功），Q 的總和等於對外淨功，不是零。
  • 「熱機可以把吸收的熱全變成功」：必須有放熱到低溫熱庫，所以 η < 1。

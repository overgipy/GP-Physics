公式與教學提示

核心公式（符號與單位）
  • 斯乃耳定律：n₁ sinθ₁ = n₂ sinθ₂　n：折射率（無單位）、θ₁：入射角、θ₂：折射角（都由法線量起）
  • 實驗 A（n₁ = 1，空氣）：sinθ₁ = n₂ · sinθ₂，所以 sinθ₁–sinθ₂ 圖是通過原點的直線，斜率 = n₂。
  • 實驗 B（n₂ = 1，空氣）：sinθ₁ = (1/n₁) · sinθ₂，斜率 = 1/n₁；折射光剛好消失時 θ₂ = 90°：sinθc = 1/n₁，所以 n₁ = 1 ÷ sinθc。
  • 全反射條件：光從折射率較大的介質射向較小的介質，且 θ₁ ≥ θc。
理想化假設：單色光、介面平整、介質均勻；忽略反射光強度隨角度的變化。
建議講解順序
  1. 實驗 A：先量 3 組，直接用 sinθ₁ ÷ sinθ₂ 算 n，看看是不是每次都一樣（常數）。
  2. 用自動掃描收集 7 組，作 sinθ₁–sinθ₂ 圖，說明斜率就是折射率。
  3. 為什麼要作圖？因為單一量測誤差大，用直線擬合可以平均掉誤差（打開讀數誤差試試）。
  4. 實驗 B：慢慢增加入射角，觀察折射角接近 90°，折射光消失；記錄臨界角並算 n。
  5. 比較兩種方法測得的 n，最後「揭曉」對答案。
可以問學生的問題
  • θ₁ 越大，sinθ₁/sinθ₂ 會變嗎？為什麼要在不同角度各量幾次？
  • 入射角很小（例如 10°）和很大（例如 70°），哪一種的量角器讀數誤差對 n 的影響比較大？
  • 為什麼從空氣射入玻璃不會發生全反射？
  • 鑽石的臨界角為什麼這麼小？對鑽石的閃耀有什麼影響？
常見迷思
  • 「角度是從介面量起」：斯乃耳定律的角度要從法線量起。
  • 「折射角永遠比入射角小」：只在從折射率小進入折射率大的介質時才成立。
  • 「全反射時光完全消失」：折射光消失，但能量全部被反射。

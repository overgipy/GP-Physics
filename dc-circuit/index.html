公式與教學提示
核心公式（符號與單位）
  • 歐姆定律：V = I R（V：伏特、I：安培、R：歐姆）。電阻的 I–V 圖是通過原點的直線，斜率 = 1／R。
  • 串聯：I 相同，Req = R1 + R2 + …；電壓依電阻大小分配，V1 : V2 = R1 : R2。
  • 並聯：V 相同，1／Req = 1／R1 + 1／R2 + …；電流與電阻成反比，I1 : I2 = R2 : R1。
  • 電池：ε = V端 + I r，端電壓 V端 = ε − I r；電路電流 I = ε ÷ (Req + r)。
  • 功率：P = V I = I²R = V²／R。電池供應的功率 ε I = 外電路消耗 ＋ 電池內部消耗（I²r）。
  • 輸出功率最大條件：外電阻 R = 內電阻 r，此時 Pmax = ε²／4r，效率只有 50%。

理想化假設：導線電阻為零；電阻為歐姆元件（R 不隨溫度變化，發光只是示意熱功率大小）；電池電動勢 ε 恆定，內電阻 r 為定值。

建議講解順序
  1. 先用「單一電阻」、r = 0：改變 ε 與 R，驗證 V = IR，看 I–V 圖斜率。
  2. 加上內電阻 r：端電壓比 ε 小；電流越大，端電壓下降越多（圖一的直線）。
  3. 串聯：問「哪個電阻比較亮？」（電流相同，R 大者 P = I²R 較大）。
  4. 並聯：問「哪個電阻比較亮？」（電壓相同，R 小者 P = V²/R 較大），與串聯對照。
  5. 混合電路：先把並聯部分化成一個等效電阻，再串聯，一步一步由外向內算。
  6. 圖二：移動 Req，找出輸出功率最大的位置；比較「功率最大」與「效率最高」不是同一件事。
可以問學生的問題
  • 串聯時，其中一個電阻變大，總電流與另一個電阻上的電壓如何變化？
  • 並聯越多個電阻，總電阻是變大還是變小？為什麼？（變小，等於增加通路）
  • 為什麼電池用久了（r 變大），手電筒會變暗？
  • 電流經過電阻，電流會「用掉」一部分嗎？（不會，電流處處相同；消耗的是電能）
常見迷思
  • 「電池提供固定電流」：電池提供（近乎）固定的電動勢；電流由整個電路的總電阻決定。
  • 「電流走過電阻後變小」：串聯電路電流處處相同，只是電位下降。
  • 「並聯的電阻越多，電流越小」：並聯越多，總電阻越小，總電流越大。

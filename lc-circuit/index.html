公式與教學提示
核心公式（符號與單位）
  • 理想 LC 電路（R = 0）：電荷 q = Q₀ cos ωt，電流 i = Δq／Δt = −ωQ₀ sin ωt；電流的最大值 I₀ = ωQ₀。q：庫侖（C）、i：安培（A）。
  • 角頻率 ω = 1／√(LC)（rad/s），週期 T = 2π√(LC)（s），頻率 f = 1／(2π√(LC))（Hz）。L：亨利（H）、C：法拉（F）。
  • 能量：電場能 UE = q²／2C、磁場能 UB = ½Li²（J）；理想時 UE + UB = Q₀²／2C 守恆，一個週期內互換兩次。
  • 有電阻（RLC 串聯）：L(Δi／Δt) + Ri + q／C = 0；衰減率 α = R／2L，振盪角頻率 ω′ = √(1／LC − R²／4L²)；臨界電阻 Rc = 2√(L／C)（Ω），R ≥ Rc 就不再振盪。電阻的發熱功率 P = i²R（W）。
  • 電磁波：c = fλ，真空中 c = 3.00 × 10⁸ m/s；電場 E、磁場 B 與前進方向三者互相垂直，E 與 B 同相，E／B = c。λ：公尺（m）。

理想化假設：導線與電感的電阻、電容的漏電都併入一個可調的 R（預設 0）；元件為理想的集總元件，不計電路本身輻射造成的能量損失；電流方向規定「流進上極板為正」。畫面上的 q、i 用解析解計算，動畫時間已放慢（實際週期只有毫秒等級）。模式 ② 的電磁波是示意圖：波長依比例尺縮放，前進速率固定代表光速，實際頻率高達百萬赫。

建議講解順序
  1. R = 0，先看電路：電容帶滿電（電場最強）→ 放電、電流增大（磁場增強）→ 電容放完時電流最大 → 電感讓電流繼續流，電容反向充電。
  2. 對照 q–t 與 i–t 圖：q 最大時 i = 0；q = 0 時 |i| 最大，兩者相差四分之一週期。
  3. 看能量圖：電場能與磁場能輪流消長，總和不變；能量變化的頻率是 q 的兩倍。
  4. 對照下方的小彈簧與類比表：L 像質量（慣性）、1／C 像彈力常數。
  5. 改變 L 或 C：預測週期變大還是變小？改變 Q₀：週期會變嗎？（不會，只改變振幅）
  6. 把 R 慢慢加大：振幅指數衰減，總能量變成熱；超過臨界電阻後不再振盪。
  7. 實驗模式：記錄 5 組以上，作 T²–LC 圖，斜率應接近 4π² ≈ 39.5；再用「未知電感」由 T²–C 圖的斜率求 L。
  8. 切到模式 ②：LC 的頻率就是發射（或接收）電磁波的頻率，用 c = fλ 算波長，調到指定電台。
可以問學生的問題
  • C 變成 4 倍，週期變成幾倍？（2 倍）L 與 C 都加倍呢？（2 倍）
  • 電容上的電荷為零的瞬間，電路的能量在哪裡？（全部是電感的磁場能）
  • 初始電荷加倍，週期、最大電流、總能量各變成幾倍？（不變、2 倍、4 倍）
  • 為什麼用 T² 對 LC 作圖，而不是 T 對 LC？（T² = 4π²·LC 才是通過原點的直線）
  • 收音機 L = 200 μH，要收聽 1000 kHz 的電台，C 要調到多少？（C = 1／(4π²f²L) ≈ 127 pF）
  • 頻率 1000 kHz 的電磁波，波長是多少？（λ = c／f = 300 m）
常見迷思
  • 「電容放完電，電流就停了」：電容放完電時電流反而最大；電感的「慣性」讓電流繼續流，替電容反向充電。
  • 「初始電荷越多，振盪越快」：週期只由 L、C 決定，與 Q₀ 無關（就像彈簧振子的週期與振幅無關）。
  • 「電場能與磁場能同時最大」：兩者此消彼長，一個最大時另一個為零。
  • 「電磁波的 E 與 B 相差 90°」：電路中的 q 與 i 相差四分之一週期，但傳播出去的電磁波，E 與 B 是同相的。
  • 「頻率越高的電磁波跑得越快」：真空中所有電磁波的速率都是 c，頻率高只是波長短。

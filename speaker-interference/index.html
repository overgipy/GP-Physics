🔊 兩喇叭的聲波干涉

兩個相干聲源　｜　路徑差 |r₁ − r₂| = mλ → 腹點（最響）、(m+½)λ → 節點（最弱）

公式與教學提示
核心公式（符號與單位）
  • 波長：λ = v / f（v：聲速 340 m/s；f：頻率，Hz）。
  • 聽者到兩喇叭的距離 r₁、r₂，路徑差 Δr = |r₁ − r₂|。
  • 兩喇叭同相：Δr = mλ（m = 0, 1, 2…）→ 建設性干涉（腹點，聲音最大）；Δr = (m + ½)λ → 破壞性干涉（節點，聲音最小）。反相時，兩種條件互換。
  • 疊加的聲壓：p = (1/r₁) cos(kr₁ − ωt) + (1/r₂) cos(kr₂ − ωt)（k = 2π/λ；ω = 2πf）。合成振幅 A = |p₁ + p₂|最大 = √(A₁² + A₂² + 2A₁A₂ cos ψ)，ψ = 2πΔr/λ。
  • 聲強（單位面積的功率）正比於振幅的平方，距離越遠越小（約 ∝ 1/r²）。因此腹點離喇叭越近越響，不同腹線上的聲音大小也不同。
  • 遠處（r ≫ d）：第 m 條腹線的方向 d sinθ = mλ；全部腹線條數 ≤ 2⌊d/λ⌋ + 1。

理想化假設：兩個點聲源（球面波）、同頻率同強度、在水平面內（俯視圖中的二維平面）傳播；忽略牆壁反射與空氣吸收；聲速 340 m/s；畫面顏色與動畫時間經過放慢，只用來觀察形狀。

建議講解順序
  1. 模式①：先把頻率調低（波長大、間距 d 小），畫面中只有一條腹線（正中央）；再調高頻率，腹線與節線條數增加。
  2. 在畫面上點一個聽者，看右下方的兩條聲壓曲線：同相疊加變大、反相疊加變小（甚至抵消）。
  3. 用「路徑差 = 幾個 λ」來判斷腹點、節點，並與畫面上的綠線、紫線對照。
  4. 模式②：講義第 8 題。先自己判斷再驗證：同在腹線上的 A 和 C 為什麼不一樣強？（距離不同）
  5. 模式③：沿直線走，音量忽大忽小（駐波般的亮暗條紋）。改變 d 與 f，條紋間距變化。
  6. 反相：兩個喇叭接線其中一個接反，中央線變成節線。
可以問學生的問題
  • 兩喇叭正中間（在中垂線上）為什麼是腹點？（路徑差為 0）
  • 降噪耳機如何利用破壞性干涉？（讓反相的聲波抵消噪音）
  • 頻率加倍，節線變多還是變少？（變多，間隔變小）
  • 為什麼家庭音響要求兩個喇叭接線方向一致？（接反會使中央音量降低，低頻特別明顯）
常見迷思
  • 「所有腹點的聲音一樣大」：腹點代表「干涉加強」，大小還受距離影響，離喇叭越近越大。
  • 「節點是聲音『沒有傳到』」：兩波都有到達，只是相互抵消；若移走一個喇叭，聲音就出現。
  • 「聲音在節點消失，能量也消失了」：能量重新分配到腹線的方向，總能量守恆。
  • 「路徑差 = λ/2 一定是破壞性」：只有兩聲源同相時才成立，反相時相反。

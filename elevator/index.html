🛗 電梯中的視重：超重與失重

磅秤讀數 N = m(g + a)　｜　a = −g 時完全失重

電梯裡的磅秤：讀數是正向力，不是重力
選擇行程與條件
行程：
乘客質量 m kg

中段等速 3 秒
播放速度
即時數據
a–t、v–t 與磅秤讀數–t 圖
挑戰：由磅秤讀數求電梯加速度
按「出題」後，加速度滑桿會被隱藏。按「出發」觀察啟動階段的磅秤讀數，算出電梯啟動的加速度大小。
公式與教學提示
核心公式（符號與單位）
  • 取向上為正，對乘客：N − mg = ma，所以磅秤讀數（正向力）N = m(g + a)（N）。
  • 磅秤刻度常用公斤重：讀數 = N／g = m(1 + a／g)（kgw）。
  • a > 0（加速度向上）：N > mg，超重；a < 0（加速度向下）：N < mg，失重；a = −g：N = 0，完全失重。
  • 加速度的方向不等於運動方向：上樓快到站時（向上減速）與下樓剛啟動時（向下加速），加速度都向下。
  • 符號：m 質量（kg）；g = 9.8 m/s²；a 電梯加速度（m/s²，向上為正）；N 磅秤對人的正向力（N）。

理想化假設：人與電梯一起運動（相對靜止）；啟動、煞車階段的加速度是定值，中段等速；磅秤瞬間反應、沒有彈簧的晃動。鋼纜斷裂時不計空氣阻力與軌道摩擦，之後安全煞車以 15 m/s² 減速。

建議講解順序
  1. 先問：電梯等速上升時，磅秤讀數比靜止時大嗎？播放「上樓」，看中段讀數。
  2. 看啟動階段：加速度向上，讀數變大；對照 a–t 圖與讀數–t 圖，形狀完全一樣。
  3. 看到站前：速度還是向上，但讀數變小——決定讀數的是加速度，不是速度。
  4. 播放「下樓」，請學生先畫出讀數–t 圖再對照。
  5. 鋼纜斷裂：讀數歸零，人「飄」起來；煞車時讀數暴增。
  6. 最後做挑戰：只看讀數反推加速度。
可以問學生的問題
  • 60 kg 的人在以 2 m/s² 向上加速的電梯裡，磅秤讀數是多少公斤重？（約 72.2 kgw）
  • 讀數變小時，電梯一定在往下走嗎？（不一定，也可能是向上減速）
  • 完全失重時，重力消失了嗎？（沒有，重力仍是 mg，只是正向力為零）
  • 太空站裡的太空人為什麼飄浮？（與太空站一起做自由落體式的圓周運動）
  • 電梯等速下降與靜止，讀數有差別嗎？（沒有，加速度都是零）
常見迷思
  • 「超重就是重力變大」：重力 mg 沒變，變的是磅秤給人的正向力。
  • 「往上就超重、往下就失重」：要看加速度方向，不是速度方向。
  • 「失重就是沒有重力」：完全失重是 N = 0，物體仍受重力並以 g 加速。
  • 「等速上升時讀數比較大」：等速時合力為零，N = mg，與靜止相同。

公式與教學提示

核心公式（符號與單位）
  • 愛因斯坦光電方程式：Kmax = hf − W　Kmax：電子最大動能（eV 或 J）、h：普朗克常數、f：光的頻率（Hz）、W：功函數（eV）
  • 截止電壓 V₀：電流剛降為 0，表示最快的電子也到不了陽極：eV₀ = Kmax（e：電子電量，所以 Kmax 以 eV 為單位時，數值上等於 V₀ 的伏特數）。
  • 所以 V₀ = (h/e)·f − W/e，V₀–f 圖是直線：斜率 = h/e，f 軸截距 = 底限頻率 f₀ = W/h，V₀ 軸截距 = −W/e。
  • 求 h：h = 斜率 × e。此頁頻率以 10¹⁴ Hz 為單位：h = 斜率 (V／10¹⁴Hz) × 1.602×10⁻¹⁹ C × 10⁻¹⁴ s。
理想化假設：每個光子只釋放一個電子；忽略接觸電位差與暗電流；I–V 曲線形狀（飽和後依 (1 − V/V₀)² 下降）是示意，但 V₀ 與頻率的關係是依公式計算。
建議講解順序
  1. 先在「展示模式」讓學生看到：頻率太低，再強的光也打不出電子。
  2. 回到實驗模式：選「未知金屬」，固定頻率畫 I–V 曲線，讓學生找截止電壓。
  3. 改變光強度再畫一條：飽和電流變大，V₀ 不變 → 光電子最大動能與光強度無關。
  4. 改變 f，記錄多組 (f, V₀)，作 V₀–f 圖。
  5. 由斜率求 h、由截距求 W，最後「揭曉」對答案。
可以問學生的問題
  • 光強度加倍，V₀ 會變嗎？飽和電流呢？為什麼古典波動理論無法解釋？
  • 換成功函數較大的金屬，V₀–f 直線怎麼移動？斜率變嗎？（平行移動，斜率不變）
  • 頻率低於 f₀ 時，為什麼沒有數據點？
  • V₀–f 圖的斜率與金屬種類有關嗎？它代表什麼常數？
常見迷思
  • 「光越亮，電子動能越大」：光強度只決定光子數量，也就是電流大小；電子最大動能由頻率決定。
  • 「只要等久一點，低頻光也能打出電子」：低於 f₀ 時，單個光子的能量不足，累積也不行（一個光子對一個電子）。
  • 「截止電壓是光電子的速率」：V₀ 對應的是 Kmax，是能量（eV₀ = Kmax = ½mv²max）。

🔍 透鏡與面鏡成像

1/p + 1/q = 1/f　｜　放大率 m = −q/p

光具座（左右拖曳物體）
選擇元件與條件
一鍵設定物距（相對焦距 f）：
物距 p20.0 cm
焦距大小 |f|8 cm
物體高度 h3.0 cm
成像結果
公式與教學提示
核心公式（符號與單位）
  • 成像公式（透鏡與球面鏡都適用）：1／p + 1／q = 1／f（p：物距、q：像距、f：焦距，單位 cm）。
  • 放大率：m = h′／h = − q／p；m < 0 表倒立，m > 0 表正立；|m| > 1 放大，|m| < 1 縮小。
  • 符號規則：凸透鏡、凹面鏡 f > 0；凹透鏡、凸面鏡 f < 0。q > 0 表實像（光線真的會聚），q < 0 表虛像（只是光線的延長線交會）。
  • 三條主光線：① 平行主軸 → 通過（或延長線通過）焦點；② 通過光心（透鏡）／鏡面頂點（反射，入射角 = 反射角）；③ 通過（或指向）焦點 → 平行主軸射出。
  • 透鏡：實像在另一側、鏡：實像在同一側（前方）。平面鏡：像距等於物距、虛像、等大、正立（左右相反）。

理想化假設：薄透鏡、近軸光線（光線靠近主軸、與主軸夾角小）；物體垂直於主軸；忽略像差與色散。畫面比例：1 cm = 12.5 px；圖形上的鏡面弧度僅為示意。

建議講解順序
  1. 先選凸透鏡，把物體從遠處（p = 3f）慢慢拖向透鏡，觀察像的位置、大小、正倒、虛實依序變化。
  2. 特別停在 p = 2f（像等大、倒立）、p = f（像在無窮遠）、p < f（正立放大虛像，放大鏡）。
  3. 引導學生自己畫出三條主光線，再開啟「顯示三條主光線」對答案。
  4. 換成凹透鏡：無論物在哪裡，像都是正立、縮小的虛像。
  5. 凹面鏡與凸透鏡一對照：規則幾乎相同，差別在實像出現在哪一側。凸面鏡與凹透鏡對照。
  6. 最後用 1／p + 1／q = 1／f 算算看，與畫面上的 q 比對。
可以問學生的問題
  • 凸透鏡成實像時，像為什麼一定是倒立的？（實像由會聚的光線形成，上下顛倒）
  • 物體放在凸透鏡 f 以內，為什麼在屏幕上看不到像？（光線發散，只有虛像）
  • 用手遮住凸透鏡的一半，像會少一半，還是變暗？（變暗，像仍完整）
  • 汽車的後視鏡為什麼用凸面鏡？（視野廣；像縮小、正立）
常見迷思
  • 「虛像就是不存在」：虛像存在，眼睛能看到，只是無法投射在屏幕上。
  • 「只有三條光線從物體射出」：實際有無數條光線；三條只是容易作圖的代表。
  • 「凹透鏡不能成像」：凹透鏡成正立縮小的虛像。

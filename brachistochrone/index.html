公式與教學提示
核心公式（符號與單位）
  • 無摩擦滑下，任一點的速率只由下降高度決定：v = √(2gy)（y 為已下降的高度）。
  • 沿軌道滑行的時間：t = ∫ ds／v——每一小段路程除以當時的速率再加起來。要快，就要「早點變快」又「路不要繞太遠」。
  • 直線斜面：t = √(2(L² + H²)／(gH))。
  • 最速降線是擺線（圓沿直線滾動時，圓周上一點的軌跡）：x = r(θ − sinθ)、y = r(1 − cosθ)（y 向下為正）；由起點滑到參數 θ 處的時間 t = θ√(r／g)。
  • 擺線的等時性：在開口向上的擺線軌道上，從任何高度由靜止釋放，到達最低點的時間都是 t = π√(r／g)。
  • 圓弧軌道（就是單擺）只有在小角度時近似等時；擺角越大，週期越長。

理想化假設：珠子視為質點、串在軌道上無摩擦滑動（不會飛離軌道），不計空氣阻力；所有軌道都在同一鉛直面內，起點、終點相同。各曲線以細小折線計算，每一小段視為等加速度運動。

建議講解順序
  1. 先只看直線與擺線，請學生預測：直線最短，會最快嗎？
  2. 釋放後看成績表與 v–t 圖：擺線一開始就衝得快，路雖然長，時間卻最短。
  3. 把 L 拉長、H 縮小：擺線會先衝到比終點更低的地方再爬上來，還是最快。
  4. 調整自訂曲線的 p，看能不能贏過擺線（不能，只能逼近）。
  5. 切到等時性：三顆珠子從不同高度出發，同時到谷底；換成圓弧就不同時了。
  6. 做實驗：t²–r 圖求 g，再挑戰未知星球。這也是惠更斯設計擺線鐘的原理。
可以問學生的問題
  • 兩點之間直線最短，為什麼不是最快？（一開始太平緩、加速太慢）
  • 「一開始垂直掉下去再水平走」會最快嗎？（不會；本頁可用很小的 p 試試，路程變太長）
  • 擺線從高處出發的珠子路比較長，為什麼和低處出發的同時到？（路長的那顆坡也比較陡、平均速率較大，剛好抵消）
  • 把這個實驗搬到月球，哪一條軌道最快？（還是擺線；所有時間都變成 √(9.8／1.62) ≈ 2.46 倍）
  • 單擺的週期真的與擺角無關嗎？（只在小角度近似成立；擺線擺才嚴格等時）
常見迷思
  • 「路程最短的直線最快」：時間 = 路程 ÷ 平均速率，直線的平均速率小。
  • 「越陡越好，先垂直落下最快」：太陡的曲線路程會變得太長，擺線是兩者之間的最佳折衷。
  • 「到終點的速率不同」：所有軌道終點速率都是 √(2gH)，不同的只是花了多少時間。
  • 「最速降線是圓弧或拋物線」：它們接近但不是；正確答案是擺線，1696 年由白努利提出、牛頓等人解出。

公式與教學提示
核心公式（符號與單位）
  • 轉動慣量 I = βmR²（kg·m²）：實心球 β = 2／5、薄球殼 2／3、實心圓柱 1／2、薄圓環 1；m：質量（kg）、R：半徑（m）。
  • 力矩與角加速度：τ = Iα；τ：力矩（N·m）、α：角加速度（rad/s²）。
  • 純滾動（不打滑）：質心速度 v = Rω、質心加速度 a = Rα。
  • 滾下斜面：沿斜面 mg sinθ − f = ma，對質心的力矩 fR = Iα，解得 a = g sinθ／(1 + β)、靜摩擦力 f = βma；到底時間 t = √(2s／a)，到底速度 v = √(2gs·sinθ／(1 + β))。
  • 動能分配：平動 ½mv²、轉動 ½Iω² = β·½mv²（J）；力學能守恆 mgh = ½mv² + ½Iω²，h = s·sinθ。
  • 不打滑的條件：需要的靜摩擦係數 μs ≥ β tanθ／(1 + β)。
  • 角動量 L = Iω（kg·m²/s）；外力矩使角動量改變 τ = ΔL／Δt；外力矩為零時角動量守恆 I₁ω₁ = I₂ω₂。轉動動能 K = ½Iω² = L²／2I。
  • 模式 ②：I = I₀ + 2mr²（兩個啞鈴視為質點，各距轉軸 r）。

理想化假設：物體是均勻剛體，斜面夠粗糙所以只滾不滑（靜摩擦不作功），不計滾動阻力與空氣阻力；滑塊則是在光滑（無摩擦）的斜面上滑下。g = 9.8 m/s²。模式 ② 的轉盤軸承無摩擦，手臂質量併入 I₀，啞鈴視為質點；收手臂的過程很快，畫面直接顯示新的角速度。

建議講解順序
  1. 先請學生預測名次，再按「釋放」：滑塊最快，接著是實心球、圓柱、空心球，圓環最慢。
  2. 把質量或半徑調大再比一次：名次與時間都不變，只跟「形狀」（β）有關。
  3. 用能量看：同樣的位能，β 越大，分給轉動的比例 β／(1+β) 越多，平動就越慢。看畫面右邊的動能長條。
  4. 用力看：靜摩擦力向上坡，一方面減慢質心，一方面提供力矩讓物體轉起來；f = βma。
  5. 實驗模式：固定物體，改變斜角測到底時間，作 a–sinθ 圖，由斜率 g／(1+β) 求 β；再挑戰「未知物體」。
  6. 切到模式 ②：先不加外力矩，收手臂看 I 變小、ω 變大、L 不變；再問動能為什麼增加。
  7. 加上外力矩：L 隨時間等速率改變（τ = ΔL／Δt），角加速度 α = τ／I。
可以問學生的問題
  • 大的實心球和小的實心球，誰先到底？（同時；a 與 m、R 無關）
  • 裝滿水（結冰）的罐頭和空罐頭，誰滾得快？（質量集中在內部的 β 較小，較快）
  • 圓環到底時，轉動動能占總動能的多少？（一半）實心球呢？（2／7）
  • 斜角太大時，哪一種形狀最容易開始打滑？（β 最大的圓環，需要的 μ 最大）
  • 滑冰選手收手臂，角動量守恆，但轉動動能增加了，能量從哪裡來？（手臂往內拉時肌肉作的功）
  • 把手臂距離減半（I₀ 很小時），角速度約變成幾倍？（約 4 倍）
常見迷思
  • 「比較重的滾得比較快」：純滾動下斜面的加速度與質量、半徑都無關，只看質量怎麼分布（β）。
  • 「有摩擦力，力學能就不守恆」：純滾動時接觸點瞬間靜止，靜摩擦力不作功，力學能守恆。
  • 「摩擦力只會讓物體變慢」：沒有摩擦力，物體只會滑、不會轉；轉動正是靠摩擦力的力矩。
  • 「角動量守恆，所以轉動動能也守恆」：K = L²／2I，L 不變而 I 變小時，K 會變大。
  • 「力矩越大，轉得越快」：力矩決定的是角加速度（角速度變化的快慢），不是角速度本身。

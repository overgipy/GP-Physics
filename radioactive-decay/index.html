公式與教學提示
核心公式（符號與單位）
  • 放射性衰變定律：N = N₀ e−λt = N₀ (½)t／T½；N 剩下的原子核數、λ 衰變常數（1/s）、T½ 半衰期。
  • 半衰期與衰變常數：T½ = ln 2／λ ≈ 0.693／λ；每經過一個半衰期，剩下的數量減半。
  • 活度（每單位時間衰變的次數）：A = λN，單位貝克（Bq = 次/秒）；活度也隨時間指數衰減，半衰期相同。
  • 取對數：ln N = ln N₀ − λt，ln N–t 圖是斜率 −λ 的直線。
  • 每一顆原子核在很短的時間 Δt 內衰變的機率是 λΔt，與它已經「活」了多久無關。
  • 碳-14 定年：由剩下的比例 N／N₀ = (½)t／5730 年 反推年代。

理想化假設：每顆原子核的衰變彼此獨立，機率不隨時間、溫度、壓力或化學狀態改變；衰變後的子核是穩定的（不再衰變）；偵測器可以數到每一次衰變。畫面上一格代表一顆原子核，真實樣品的數量是 10²⁰ 以上，所以實際的曲線非常平滑。

建議講解順序
  1. 先用 100 顆：開始後看哪一顆先衰變——無法預測；N–t 圖歪歪扭扭。
  2. 換成 1600 顆：個別仍然隨機，但整體很接近理論曲線——大量統計才有規律。
  3. 暫停在 1、2、3 個半衰期，數一數剩下的數量：一半、四分之一、八分之一。
  4. 看活度圖：一開始衰變得最快，越來越慢，形狀與 N–t 一樣。
  5. 問：兩個半衰期後會全部衰變完嗎？
  6. 做實驗：ln N–t 圖求半衰期，再挑戰未知核種；最後換成碳-14 談定年。
可以問學生的問題
  • 經過 3 個半衰期，還剩下原來的幾分之幾？衰變掉幾分之幾？（1／8；7／8）
  • 某一顆原子核已經撐過 2 個半衰期，它在下一個半衰期內衰變的機率是多少？（仍是 1／2）
  • 樣品的活度降到原來的 1／16 需要多久？（4 個半衰期）
  • 古木中碳-14 的含量是活樹的 25%，它大約多久以前死亡？（約 11,460 年）
  • 半衰期短的核種比較危險還是半衰期長的？（同樣數量下半衰期短的活度大，但很快就衰變完；要看情況）
常見迷思
  • 「兩個半衰期就全部衰變完」：每個半衰期只減少「當時剩下」的一半，兩個半衰期後還剩 1／4。
  • 「放越久的原子核越容易衰變」：衰變機率與原子核的「年齡」無關，沒有老化這回事。
  • 「加熱或加壓可以讓衰變變快」：衰變是原子核內部的過程，幾乎不受溫度、壓力、化學反應影響。
  • 「半衰期是某一顆原子核的壽命的一半」：半衰期是統計量，描述一大群原子核減半所需的時間。
